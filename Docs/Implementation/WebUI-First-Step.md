# WebUI 第一阶段实现

- 日期：2026-10-09
- 工具链：Rust 1.99.0，Rust 2024 Edition
- 构建模式：仅 `ui`
- 架构依据：[设计 v0.10](../Design.md)

本阶段建立基础控件从 Rust 声明到浏览器交互的最小闭环。WebUI 在浏览器中运行前端 WASM，业务引擎独立运行；本地开发宿主同时提供静态资源与引擎端点，二者不共享可变业务对象。

## 模块职责

| 模块 | 责任 |
| --- | --- |
| bern-core | 平台无关的组件 IR、类型化字段、命令描述、JSON 协议与引擎接口 |
| bern-macros | 受限 `#[component]` 与 `ui!` 解析及语法诊断 |
| bern-web | 验证组件描述，导出 WebUI 静态资源与构建清单 |
| bern-web-runtime | Rust WASM 会话状态与主题算法；JS 负责 DOM 和 WebSocket 桥接 |
| bern-server | 独立引擎的串行命令调度、HTTP/WS 接口与快照广播 |
| examples/basic | 控件示例、计数器业务和本阶段构建启动入口 |

## 已纳入的控件

| 控件 | 当前能力 |
| --- | --- |
| Text | 字面量、引擎或会话字段的展示绑定 |
| Button | 绑定已注册的无参数引擎命令 |
| TextInput | 字符串会话字段，自动经过标准编辑命令更新语义草稿 |
| Checkbox | 布尔会话字段，通过标准会话动作更新 |
| Row 与 Column | 间距、内边距和有稳定 ID 的静态子节点 |

`#[component]` 首版只接受无参数、无泛型的同步组件函数，函数体必须为一个 `ui!`。可用属性值为字面量或已声明常量路径；不支持任意表达式、回调或动态组件工厂。所有控件必须有非重复 ID。

语法与部分类型问题在 Rust 编译阶段失败；命令是否存在于应用目录、字段作用域和 ID 唯一性在构建导出阶段校验。当前构建入口是示例可执行程序的 `build` 子命令，尚无通用 `bern build` 工具和跨 crate 描述提取器。

## 状态与命令边界

引擎通过 `Engine` 接口提供命令目录、快照和处理器，完全不依赖 DOM。宿主对版本、引擎身份、请求结构、目录和空参数约束进行校验，再串行调用同一个引擎。revision 在 JSON 中是十进制字符串，避免 JavaScript 截断 64 位整数。

前端 WASM 持有每页独立的会话草稿。原生输入框的临时编辑缓冲与输入法组合属于输入采样，写入可被其他控件观察的语义草稿必须经过会话命令；应用代码没有任意 DOM 事件回调入口。这个切片尚未完整实现框架的导航、焦点会话协议或所有原生交互拦截契约。

断线保留本地草稿，业务快照标记为失联，引擎操作不可用。恢复连接取得完整快照；已发请求不自动重放。请求 ID 只是相关性标识，首版没有实现幂等键、取消和长任务协议。成功命令处理器为同步执行，错误处理器必须保证不修改业务状态。

HTTP JSON 与 WebSocket 使用相同引擎调度；当前没有应用 CLI/MCP 适配或跨连接路由到前端会话的协议，不据此宣称四入口已全部实现。

## 主题与构建

深浅色语义 token 由 Rust 前端运行时生成，浏览器跟随系统外观并应用同一套语义样式。应用无需维护两套配色。前端 WASM 包不链接计数器或服务器 crate；`build.json` 明确记录 `mode: ui` 和 `engine_included: false`。

本阶段不包含品牌色配置、完整主题配方扩展、高对比的全矩阵认证或逐平台视觉验收。基础控件的浅色、深色、键盘、输入法和窄屏行为应随每次相关修改验证。

本地宿主仅面向开发，绑定 loopback，并校验浏览器来源；连接地址本身不是授权凭据。远程部署需要另行实现并验证身份、权限与来源配置。Web 应用 `app` 构建及原生后端仍未实现，不进行静默模式回退。

## 本次验证

2026-10-09 在 macOS、Rust 1.99.0 与 Codex 内置浏览器中完成：

- 全工作区 36 项单元、集成及文档测试通过，其中 5 项检查非法组件声明无法编译。
- `cargo fmt --all --check` 和 `cargo clippy --workspace --all-targets -- -D warnings` 通过；Clippy 在当前 macOS 工具链上检查库、测试与示例目标。
- 前端 WASM release 构建及 `wasm-bindgen` 导出成功。前端依赖树不包含示例引擎和服务器 crate。
- Node.js 网络烟测通过：两个 WebSocket 客户端和 HTTP 修改同一计数器；非法请求不修改状态；跨源写入被拒绝；静态 WASM 的 MIME 正确。
- 浏览器验证按钮点击与 Enter、复选框 Space、中文文本编辑与绑定预览；两个页面共享计数、草稿各自独立。
- 停止并重启服务：断线禁用引擎按钮，本地草稿仍可编辑；恢复后重新取得新引擎的计数，保留当前页草稿。
- 默认系统深色与临时外观测试页的浅色／深色切换均已目视检查；390 像素视口无横向溢出。外观测试使用模拟媒体查询事件，未改动操作系统外观。

这不代表跨浏览器或真机矩阵已完成。真实输入法组合输入、移动设备和辅助技术仍需后续专项验收；本次中文输入验证使用浏览器自动化填充。
