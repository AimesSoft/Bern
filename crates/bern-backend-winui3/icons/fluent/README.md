# Fluent System Icons

These are the `d` attributes of the 20-unit **Comment Quote**, **Comment Text**
and **Subtitles** SVGs (Regular and Filled) from [Microsoft Fluent System
Icons](https://github.com/microsoft/fluentui-system-icons/tree/4e8620a7c6ba5fba3f3f3f6908dd06b3a9332be6/assets).
Each file is named after its upstream SVG. Keep both weights of a symbol from
the same family, size and revision. The XAML host supplies the foreground;
there is no baked-in background or colour. See [LICENSE](LICENSE).
